# So Fetch Photobooth

A Mean Girls-inspired photobooth with three-photo strips, filters, iconic movie lines, and single-frame video recording up to 30 seconds.

## Run locally

Serve this folder over HTTPS or through a local development server. Camera and microphone permissions require a secure context such as HTTPS or localhost.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
5. Save and open the generated Pages URL.

Friends need to allow camera access. Microphone access is optional and only requested when **Include sound** is selected.
